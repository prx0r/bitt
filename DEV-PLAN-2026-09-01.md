## Status: Active Integration

## Critical Fixes (do first)

### 1. Emission calculation is wrong
Current code sums all neuron emissions and calls it "miner pool". Emission in metagraph is per-tempo, not per-day. Need to account for:
- Tempo (blocks per epoch)
- Owner cut (~18%)
- Miner vs validator split
- Epoch frequency

### 2. Snapshots not block-pinned
`_sdk_subnet_info()`, `_sdk_burn()`, `_sdk_metagraph()` are separate latest-state requests. Use `sub.at(block)` to pin all queries to one block.

### 3. Metagraph key mismatch
`_sdk_metagraph()` returns `neuron_count` but cross-source validation looks for `metagraph["neurons"]`.

### 4. Tempo not propagated
Snapshot defaults `tempo_blocks=100` but current default is 360.

### 5. .db in git
Move `scanner_store.db` and `oracle.db` outside git.

## Architecture (implement next)

```
bitt-chaind      — own Finney lite node, finalized-block ingestion
bitt-state       — block-pinned state materializer
bitt-history     — archive backfill
bitt-registry    — all 128 subnet identities, GitHub/docs/API discovery
bitt-mechanism   — validator/reward/benchmark extraction
bitt-probe       — public API/leaderboard health
bitt-market      — Taostats, TAO.app, TaoMarketCap
bitt-oracle      — discrepancies, opportunity features, confidence
bitt-lab         — local reproduction, sealed evaluation, Hydra/CGE
bitt-dashboard   — projection only, never source of truth
```

## Data collection cadence

| Data | Trigger |
|------|---------|
| Finalized block header | every block |
| Extrinsics/events | every block |
| Dynamic subnet prices | every block / few blocks |

| Global subnet state | 1-5 min |
| Priority subnet metagraph | 30-60 sec |
| All metagraphs | 5-15 min |
| Full weights/bonds | epoch or weight event |
| Mechagraphs | epoch / mechanism change |
| GitHub state | commit/release or 5-15 min |

| Docs/community | hourly/daily |

## SubnetSurfaceRegistry

Track per subnet:
- Chain: metagraph, weights, bonds, epoch, burn
- Repos: validator, miner, benchmark
- APIs: platform, leaderboard, schema
- Benchmark: name, version
- Community: site, X, Discord

## Key principle

> Bittensor chain state is the economic/coordination truth. It is not the complete truth about what a subnet is doing.

Chain for economics. Current validator implementation / live owner API for mechanism semantics. GitHub for code. APIs for live benchmarks. Never overwrite facts with another source — store competing observations and derive current belief.
